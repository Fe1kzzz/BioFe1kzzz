# Burp Rust Information Bot

Бот для отправки информации о проекте Burp Rust в Discord канал.

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте `.env` файл:
```bash
cp .env.example .env
```

3. Заполните `.env`:
- `DISCORD_TOKEN` - токен Discord бота
- `INFO_CHANNEL_ID` - ID канала для информации

## Использование

### Отправить информационную панель:
```bash
npm run send
```

Бот отправит 4 embed сообщения:
1. Информация по проекту
2. Расписание серверов
3. Полезные команды
4. Официальные ссылки (с кнопками)

## Настройка

Отредактируйте `config.json` чтобы изменить:
- Название проекта
- Описание
- Расписание вайпов
- Список серверов
- Команды
- Ссылки
- Кнопки
